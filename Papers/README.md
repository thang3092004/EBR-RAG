## Cach dung trong do an

- `VideoRAG` dung de mo ta baseline ma do an dang cai tien.
- Nhom `tracking / MOT` dung de giai thich vi sao co the tao local tracklets.
- Nhom `long-video identity / character grounding` dung de bao ve y tuong
  global entity ID cho video dai.
- Nhom `segmentation / object memory` dung cho object, animal, va vat the khong
  phai person.
- Nhom `audio / speaker` dung cho thuyet minh, hoi thoai, speaker diarization,
  va active speaker.
- Nhom `scene graph / visual grounding` dung de lien he entity IDs voi qua
  trinh sinh graph.
